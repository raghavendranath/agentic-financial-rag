# Exploratory T5-small baseline

The public base model is `google-t5/t5-small`, revision `df1b051c49625cf57a3d0d8d3863ed4d13564fe4`. The training protocol, data checksums and saved predictions are in `experiments/t5-small`.

Training uses 4,988 FinQA training examples after excluding 1,263 examples sharing the selected development/evaluation filings, 100 development questions and the same 50 evaluation questions as the hosted FinQA runs. Its question-only lexical reader chooses ten public rows. Input/target limits are 512/128 tokens; AdamW learning rate 0.0003, weight decay 0.01, warmup fraction 0.1, gradient clip 1, batch 8, seed 18, exactly three epochs, greedy decoding. Four evaluation contexts are truncated.

Saved results are 12/48 numerical matches (.250) and 12/50 overall (.240). This differs in context, capacity and training from the BGE/hosted-model arms and is not a matched retrieval ablation or the unavailable historical FinQA-T5 model.

Rescore saved predictions without the checkpoint:

```bash
cd experiments/t5-small
python evaluate.py score
```

To train a new checkpoint, make a separate copy of this repository (preserving the sibling experiment layout), remove the T5 experiment's saved generated outputs and training receipts in that new copy only, install the full environment, and run `python train.py`. The script chooses MPS when available and otherwise CPU. It downloads only the pinned base checkpoint. Do not run `prepare.py` over the published protocol: it resolves a live model revision, whereas the saved protocol already pins the evaluated revision and selected inputs.

Run `python evaluate.py generate --device cpu` in that new experiment, then `python evaluate.py score`. New training outputs are separate stochastic results; the training script is available for reuse, not a promise of bitwise checkpoint reproducibility. The original checkpoint is not committed to Git.
